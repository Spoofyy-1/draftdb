# Novel-data research sweep (2026-09-08)

Ten reports from a parallel research sweep on predictors the model does not use yet: proven ones from the literature and public draft models, and novel free sources that are datable before draft night. Each report ranks items by expected value with sources, dating method, collection cost and leakage risk.

| File | Slice |
|---|---|
| 01_literature_predictors.md | Peer-reviewed and quantitative-analytics predictors not in the model |
| 02_public_models_features.md | Feature sets and reported importances of public draft models |
| 03_physical_combine.md | Combine, anthropometric and growth evidence |
| 04_draft_biases.md | Documented draft-market biases to exploit |
| 05_bio_youth_pathway.md | Biographical and youth-pathway predictors |
| 06_injury_durability.md | Injury history, durability and availability |
| 07_international_pathways.md | International and non-college pathway signals |
| 08_novel_sources.md | Scan of free, historically deep sources |
| 09_market_meta.md | Market and meta sources (agents, odds, Wikidata, news volume) |
| 10_wayback_scouting.md | Archived scouting media (DraftExpress, NBADraft.net, boards) |

Collectors launched from this sweep (Euroleague API spine and U18 block, NBADraft.net grades, Torvik all-D1 context, ncaahoopR game logs, DraftExpress youth measurements, Wikipedia rule-based features, FIBA youth age-relative block, draft-page green-room list, boards-versus-mocks fit gap) feed data versions v4.9 onward; results are recorded in EXPERIMENTS.md as they are tested with the confirmed gate.
